# Thinkies Application Examples

## Prioritization in Product Development

**Situation:** Overwhelmed by huge backlog. Everyone says everything is important.

- **Half in Half** — Ask "Which half can we deliver in half the time?" Reveals what's truly essential.
- **Customer's Voice** — Unify stakeholders into a single coherent voice.
- **Compared to What?** — "This is the most important feature." Compared to what?

## Technical Debt and Refactoring

**Situation:** Lot of technical debt. Every attempt to fix it feels too big.

- **Scale Down** — What smaller thing could make the big problem more manageable?
- **Grow Then Split** — Start small, grow it, split naturally when uncomfortably large.
- **Easy Bit** — Pick the absolute easiest small improvement to build momentum.

## Deciding Between New Product Ideas

**Situation:** Debating between two features. Both seem valuable.

- **Parallel Decision** — Ask "Why not both?" Explore both until one clearly wins.
- **Set-Based Design** — Implement small parts of each until one is clearly superior.
- **Defer Decision** — Wait. "What if we delay deciding for a while?"

## Delivery Speed Pressures

**Situation:** Leadership says "go faster!" Team already at maximum capacity.

- **Latency, Throughput, & Variance** — Ask if focus is latency or throughput. Reducing variance often improves perceived speed.
- **Reduce Utilization** — Counterintuitively, reducing utilization can improve flow and reduce wait times.
- **Work/Wait Ratio** — Trace a work item, add up work time vs waiting time. Improve the ratio.
